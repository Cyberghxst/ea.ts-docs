Logs a message to the console using Logger API.
## Parameters
|  Name   |     Description     | Enforced | Default Value |
|---------|---------------------|----------|---------------|
| Type    | The type of log.    | Yes      | None          |
| Message | The message to log. | Yes      | None          |
## Example
```eats
$logger[type;...message]
```
