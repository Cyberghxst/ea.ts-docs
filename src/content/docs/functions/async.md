Wraps a function to be executed asynchronously.
## Parameters
| Name |             Description             | Enforced | Default Value |
|------|-------------------------------------|----------|---------------|
| Code | The code to execute asynchronously. | Yes      | None          |
## Example
```eats
$async[code]
```
